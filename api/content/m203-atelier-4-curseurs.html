Un curseur permet de parcourir le résultat d'un SELECT ligne par ligne dans une procédure stockée, pour appliquer un traitement à chaque enregistrement : un calcul, une condition, une mise à jour.

Les 4 étapes et la fin de lecture

Étape Action Commande
Déclaration Préparer le curseur DECLARE nom CURSOR FOR SELECT …;
Ouverture Démarrer la lecture OPEN nom;
Lecture Récupérer une ligne dans des variables FETCH nom INTO v1, v2;
Fermeture Libérer les ressources CLOSE nom;
Fin de lecture Éviter l'erreur après la dernière ligne DECLARE CONTINUE HANDLER FOR NOT FOUND SET fin = TRUE;

Ordre imposé par MySQL dans le bloc BEGIN … END : d'abord les variables, puis le curseur, puis le handler.

Exemple : lecture des stagiaires

DELIMITER //
CREATE PROCEDURE exemple_curseur()
BEGIN
    DECLARE var1 INT;
    DECLARE var2 VARCHAR(100);
    DECLARE fin_curseur BOOLEAN DEFAULT FALSE;
    DECLARE mon_curseur CURSOR FOR
        SELECT id, nom FROM stagiaires;
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET fin_curseur = TRUE;

    OPEN mon_curseur;
    boucle_lecture: LOOP
        FETCH mon_curseur INTO var1, var2;
        IF fin_curseur THEN
            LEAVE boucle_lecture;
        END IF;
        SELECT CONCAT('Lecture du stagiaire : ', var2) AS message;
    END LOOP;
    CLOSE mon_curseur;
END //
DELIMITER ;

CALL exemple_curseur();

Avec 3 stagiaires (Ali, Sara, Mouna), la procédure affiche 3 messages, un par ligne lue. Après la dernière ligne, le FETCH ne trouve plus rien : le handler met fin_curseur à TRUE et LEAVE sort de la boucle.

Cas pratique : facturation avec curseur

CREATE TABLE IF NOT EXISTS facture (
    id_facture INT AUTO_INCREMENT PRIMARY KEY,
    nom_client VARCHAR(100),
    qte_eau INT,
    montant DECIMAL(10, 2)
);

INSERT INTO facture (nom_client, qte_eau) VALUES
('Client 1', 9), ('Client 2', 15), ('Client 3', 25);

DELIMITER //
CREATE PROCEDURE calculer_factures()
BEGIN
    DECLARE v_id INT;
    DECLARE v_qte INT;
    DECLARE v_montant DECIMAL(10,2);
    DECLARE fin BOOLEAN DEFAULT FALSE;
    DECLARE curseur_facture CURSOR FOR
        SELECT id_facture, qte_eau FROM facture;
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET fin = TRUE;

    OPEN curseur_facture;
    boucle_factures: LOOP
        FETCH curseur_facture INTO v_id, v_qte;
        IF fin THEN
            LEAVE boucle_factures;
        END IF;
        SET v_montant = v_qte * 1.25;
        UPDATE facture SET montant = v_montant WHERE id_facture = v_id;
    END LOOP;
    CLOSE curseur_facture;
END //
DELIMITER ;

CALL calculer_factures();
SELECT * FROM facture;

Avant l'appel, la colonne montant vaut NULL. Après : 11,25 (9 m³), 18,75 (15 m³) et 31,25 (25 m³), soit quantité × 1,25.

Exercice : attribuer une mention à chaque étudiant

CREATE TABLE notes (
    id_note INT AUTO_INCREMENT PRIMARY KEY,
    nom_etudiant VARCHAR(100),
    note DECIMAL(4,2),
    mention VARCHAR(20)
);

INSERT INTO notes (nom_etudiant, note) VALUES
('Ali', 17.50), ('Sara', 14.25), ('Khalid', 11.00), ('Mouna', 8.75),
('Youssef', 19.00), ('Imane', 9.99), ('Omar', 16.00);

DELIMITER //
CREATE PROCEDURE attribuer_mentions()
BEGIN
    DECLARE v_id INT;
    DECLARE v_note DECIMAL(4,2);
    DECLARE v_mention VARCHAR(20);
    DECLARE fin BOOLEAN DEFAULT FALSE;
    DECLARE curseur_notes CURSOR FOR
        SELECT id_note, note FROM notes;
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET fin = TRUE;

    OPEN curseur_notes;
    boucle_notes: LOOP
        FETCH curseur_notes INTO v_id, v_note;
        IF fin THEN
            LEAVE boucle_notes;
        END IF;

        IF v_note >= 16 THEN
            SET v_mention = 'Excellent';
        ELSEIF v_note >= 14 THEN
            SET v_mention = 'Bien';
        ELSEIF v_note >= 10 THEN
            SET v_mention = 'Passable';
        ELSE
            SET v_mention = 'Insuffisant';
        END IF;

        UPDATE notes SET mention = v_mention WHERE id_note = v_id;
    END LOOP;
    CLOSE curseur_notes;
END //
DELIMITER ;

CALL attribuer_mentions();
SELECT * FROM notes;

Barème choisi : Excellent à partir de 16, Bien de 14 à 16, Passable de 10 à 14, Insuffisant en dessous de 10. Les cas limites sont testés : 16,00 → Excellent, 9,99 → Insuffisant.

Mention Étudiants Notes
Excellent Ali, Youssef, Omar 17,50 · 19,00 · 16,00
Bien Sara 14,25
Passable Khalid 11,00
Insuffisant Mouna, Imane 8,75 · 9,99

À retenir

Le curseur est utile quand chaque ligne demande un traitement différent, comme ici une mention qui dépend de la note.

Pour un calcul simple appliqué à toutes les lignes, une seule requête est plus rapide qu'une boucle :

UPDATE notes SET mention = CASE
    WHEN note >= 16 THEN 'Excellent'
    WHEN note >= 14 THEN 'Bien'
    WHEN note >= 10 THEN 'Passable'
    ELSE 'Insuffisant'
END;

Le curseur reste l'outil adapté quand le traitement d'une ligne dépend d'une logique plus complexe : appels à d'autres procédures, cumuls, messages.
