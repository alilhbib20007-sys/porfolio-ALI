Exécuté sur Aiven : MySQL 8.4.11, base atelier2_procedures, 0 erreur. Fichiers : script SQL complet des ateliers 2, 3 et 4 · résultats bruts d'Aiven.

Une procédure stockée est un programme enregistré dans la base : elle regroupe plusieurs instructions SQL qu'on lance avec CALL. Une fonction stockée fonctionne pareil, mais retourne une valeur et s'utilise dans un SELECT.

Procédure Fonction
Appel CALL nom(...) SELECT nom(...)
Valeur de retour Aucune (mais paramètres OUT / INOUT) Une seule, avec RETURN
Peut renvoyer un tableau de résultats Oui Non

Deux adaptations pour Aiven

  • DELIMITER // au lieu de DELIMITER /. Le caractère / sert aussi à la division (inscrits / capacite dans l'atelier 3) : le client mysql couperait la procédure en deux.
  • DETERMINISTIC, NO SQL ou READS SQL DATA sur chaque fonction. Le journal binaire est actif sur Aiven et l'utilisateur ne peut pas modifier log_bin_trust_function_creators : sans ces mots-clés, MySQL refuse la fonction (erreur 1418).

Table stagiaires et premiers exemples

CREATE TABLE stagiaires (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nom VARCHAR(100),
    ville VARCHAR(100)
);

INSERT INTO stagiaires (nom, ville) VALUES
('Ali','Casablanca'), ('Sara','Rabat'), ('Khalid','Casablanca'),
('Mouna','Marrakech'), ('Youssef','Rabat');

DELIMITER //
CREATE PROCEDURE pc1()
BEGIN
    SELECT * FROM stagiaires;
END //

CREATE FUNCTION somme(a INT, b INT)
RETURNS INT
DETERMINISTIC NO SQL
BEGIN
    DECLARE s INT;
    SET s = a + b;
    RETURN s;
END //
DELIMITER ;

CALL pc1();
SELECT somme(1, 2);

CALL pc1() affiche les 5 stagiaires, somme(1, 2) renvoie 3.

Procédures et fonction sur les stagiaires

DELIMITER //
CREATE PROCEDURE afficher_stagiaires_par_ville(IN ville_param VARCHAR(100))
BEGIN
    SELECT * FROM stagiaires WHERE ville = ville_param;
END //

CREATE PROCEDURE compter_stagiaires()
BEGIN
    DECLARE total INT;
    SELECT COUNT(*) INTO total FROM stagiaires;
    SELECT total AS 'Nombre de stagiaires';
END //

CREATE FUNCTION nombre_stagiaires_par_ville(ville_param VARCHAR(100))
RETURNS INT
READS SQL DATA
BEGIN
    DECLARE total INT;
    SELECT COUNT(*) INTO total FROM stagiaires WHERE ville = ville_param;
    RETURN total;
END //
DELIMITER ;

CALL afficher_stagiaires_par_ville('Casablanca');   -- Ali, Khalid
CALL compter_stagiaires();                          -- 5
SELECT nombre_stagiaires_par_ville('Rabat');        -- 2

Structures de contrôle

Structure Rôle
IF … ELSEIF … ELSE … END IF Exécuter selon une condition
CASE … WHEN … END CASE Choisir parmi plusieurs valeurs
WHILE … DO … END WHILE Répéter tant que la condition est vraie (0 fois possible)
REPEAT … UNTIL … END REPEAT Répéter jusqu'à ce que la condition soit vraie (au moins 1 fois)

Exemple pratique : facturation de l'eau

Barème : 0 à 10 m³ à 1 €, 11 à 30 m³ à 1,5 €, au-delà à 2 € par m³.

CREATE TABLE facture (
    id_facture INT AUTO_INCREMENT PRIMARY KEY,
    nom_client VARCHAR(255),
    qte_eau INT
);

DELIMITER //
CREATE PROCEDURE inserer_factures()
BEGIN
    DECLARE compteur INT DEFAULT 1;
    WHILE compteur <= 100 DO
        INSERT INTO facture (nom_client, qte_eau)
        VALUES (CONCAT('Client', compteur), compteur);
        SET compteur = compteur + 1;
    END WHILE;
END //

CREATE FUNCTION calculer_montant(qte INT)
RETURNS DECIMAL(10,2)
DETERMINISTIC NO SQL
BEGIN
    DECLARE montant DECIMAL(10,2);
    IF qte <= 10 THEN
        SET montant = qte * 1;
    ELSEIF qte <= 30 THEN
        SET montant = (10 * 1) + (qte - 10) * 1.5;
    ELSE
        SET montant = (10 * 1) + (20 * 1.5) + (qte - 30) * 2;
    END IF;
    RETURN montant;
END //
DELIMITER ;

CALL inserer_factures();
SELECT id_facture, nom_client, qte_eau, calculer_montant(qte_eau) AS montant_a_payer
FROM facture;

La boucle WHILE a inséré 100 factures (de 1 à 100 m³). Vérification aux limites des tranches :

m³ 10 11 30 31 100
Montant 10,00 11,50 40,00 42,00 180,00

Total des 100 factures : 8 340,00 €.

Paramètres IN, OUT et INOUT

DELIMITER //
-- IN : valeur d'entrée
CREATE PROCEDURE supprimer_stagiaire(IN p_id INT)
BEGIN
    DELETE FROM stagiaires WHERE id = p_id;
END //

-- OUT : valeur de sortie
CREATE PROCEDURE compter_stagiaires_out(OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total FROM stagiaires;
END //

-- INOUT : entrée puis sortie
CREATE PROCEDURE augmenter_stock(INOUT qte INT, IN p_id INT)
BEGIN
    UPDATE produits SET stock = stock + qte WHERE id = p_id;
    SELECT stock INTO qte FROM produits WHERE id = p_id;
END //
DELIMITER ;

CALL supprimer_stagiaire(5);           -- Youssef supprimé
CALL compter_stagiaires_out(@nb);
SELECT @nb AS total_stagiaires;        -- 4

SET @ajout = 10;
CALL augmenter_stock(@ajout, 1);
SELECT @ajout AS nouveau_stock;        -- 15 + 10 = 25

Pour augmenter_stock, j'ai créé une petite table produits (id, nom, stock) avec Clavier (15) et Souris (40). @ajout entre avec 10 et ressort avec le nouveau stock, 25.

Type Direction Exemple Résultat
IN Entrée id à supprimer Youssef supprimé, il reste 4 stagiaires
OUT Sortie nombre total @nb = 4
INOUT Entrée puis sortie quantité ajoutée @ajout passe de 10 à 25

Suppression des procédures et fonctions

DROP PROCEDURE IF EXISTS afficher_stagiaires_par_ville;
DROP PROCEDURE IF EXISTS compter_stagiaires;
DROP FUNCTION IF EXISTS nombre_stagiaires_par_ville;

Après suppression, il reste 7 routines (calculer_montant, somme, augmenter_stock, compter_stagiaires_out, inserer_factures, pc1, supprimer_stagiaire). IF EXISTS évite une erreur si la routine n'existe pas.
